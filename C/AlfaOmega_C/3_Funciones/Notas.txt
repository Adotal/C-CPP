-------------STRUCTS-----------------
Los structs sirven para agrupar variables de distinto tipo
Sintaxis:

struct tipo {
	campos
} nombreVariable;

*tipo no es obligatorio, si está se podrán definir más instancias de este tipo.
*nombreVariable no es obligatorio si sólo se necesita definir un nuevo tipo de struct, si se especifica, se crea una variable con ese nombre.

Se accede a las variables con 
NombreStruct.nombreCampo = X;

También puede haber arrays de structs

Se puede inicializar en su declaración:
struct {
	int a;
	char c;
} cosa = {5, 'F'};

A diferencia de arreglos, los structs si se pueden copiar con una asignación:
str1 = str2;


UNION: struct que sólo puede tener el valor de un miembro
